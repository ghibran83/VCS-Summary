    <h1>Version Control System (VCS) Summary</h1>
    <h2>Version Control System ?</h2>
        <p>Version Control System adalah sistem yang membantu kita melacak perubahan pada file atau proyek dari waktu ke waktu. 
        Ibaratnya seperti mesin waktu untuk proyek kita—bisa kembali ke versi sebelumnya, melihat siapa yang mengubah apa,
        dan berkolaborasi tanpa takut file ketimpa.</p>
    <h2>Jenis-Jenis VCS</h2>
        <p>Lokal : Semua versi disimpan di komputer pengguna</p>
        <p>Terpusat : Ada satu server utama, semua user terhubung ke sana</p>
        <p>Terdistribusi : Setiap user punya salinan lengkap dari repo</p>
    <h2>Git ? Github ?</h2>
        <p>Git : adalah tools VCS yang populer untuk mengatur versi proyek secara lokal.</p>
        <p>Github : adalah platform online untuk menyimpan repo Git dan berkolaborasi dengan tim.</p>
    <h2>Manfaat VCS</h2>
        <p>. Tracking perubahan dan histori editan</p>
        <p>. Kolaborasi tim tanpa konflik</p>
        <p>. Backup otomatis dan aman</p>
        <p>. Eksperimen bebas dengan branch</p>
    <h2>Alur Kerja Git</h2>
    <p>1. git init – mulai proyek</p>
    <p>2. git add – pilih file yang mau disimpan</p>
    <p>3. git commit – simpan perubahan dengan pesan</p>
    <p>4. git push – kirim ke GitHub</p>
    <p>5. git pull – ambil update dari GitHub</p>
